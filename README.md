# Pulse Board

**Pulse Board** is a real-time collaborative whiteboard and online application that allows multiple users to draw, create shapes, and organize their work on a shared canvas. Users can customize their drawings with colors, brush sizes, and shapes, and save elements into collections for easy organization and sharing.

---

## Features

- Real-time drawing with multiple users.
- Customizable tools: colors, brush sizes, and shapes.
- Organize drawings into collections.
- Responsive interface for desktop and mobile devices.

---

## Tools & Technologies Used

- **Front-end:** React, JSX, Context API, CSS
- **Back-end:** Node.js, Express, Socket.io, Apache Kafka
- **Database:** PostgreSQL

---

## Purpose

This application is designed to facilitate collaboration, brainstorming, and live visual communication, making it easy for teams or individuals to work together on ideas in real time.
